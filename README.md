# Krvavý Chaos

A Twitch **Video Overlay** extension for the Czech Blood on the Clocktower (BotC) community stream *"Krvavá hodina odbila"*.

The extension shows live game info (players, characters, roles, game phase) overlaid on the stream video, with hoverable elements revealing additional details to viewers. Multiple streamers playing the same game can have their channels linked to share a single game state, which is updated in real time by authorized editors.

---

## Monorepo Structure

```
krvavy-chaos/
├── packages/
│   ├── extension/   — Vite + Svelte 5 static overlay (uploaded to Twitch CDN)
│   ├── web/         — SvelteKit editor app + REST API (deployed to Vercel)
│   └── shared/      — Shared TypeScript types and reusable Svelte 5 components
├── pnpm-workspace.yaml
└── package.json
```

---

## Setup

```bash
# Install dependencies
pnpm install

# Start dev servers
pnpm dev:extension   # Vite dev server for the overlay
pnpm dev:web         # SvelteKit dev server for the editor app

# Build
pnpm build:extension # Builds and zips the overlay to dist/app.zip
pnpm build:web       # Builds the SvelteKit app
pnpm build           # Builds all packages
```

## Architecture

The project uses a **hybrid approach** optimised for zero-cost hosting:

| Layer | Tech | Hosting |
|---|---|---|
| Overlay extension | Vite + Svelte 5 | Twitch CDN (uploaded as `app.zip`) |
| Editor + API | SvelteKit | Vercel (free tier) |
| Database | Drizzle ORM + Turso (libSQL) | Turso free tier |

### User Flow
1. anyone can login using Twitch OAuth, becoming a user
2. user has a unique sessionId generated by the app when they first login, that can be manually rerolled if needed, and which they can share with other users to link their channels together
3. user can give other users editor permissions to their game, allowing them to update the game state as well
3. user can create/update game which they either created or have editor permissions for, which updates the game state in the database and sends a PubSub message to all linked channels to update their overlays in real time
4. user can have only one active game at a time, but can have multiple non-active games in the database that they can prepare in advance and switch between
5. the overlay extension listens for PubSub messages and updates the game state in real time as they come in, showing the latest info to viewers
6. the extension knows which game to show based on the channel it is running on, and the sessionId of the user who owns that channel, which is sent as a query parameter when the extension iframe loads

## Packages

### `@krvavy-chaos/extension`
Plain Vite + Svelte 5 app (no SvelteKit). Built to `dist/` and automatically zipped to `extension.zip` for upload to the Twitch Developer Console.

### `@krvavy-chaos/web`
SvelteKit app deployed to Vercel. Serves as both the editor UI and the REST API backend that the extension calls.

### `@krvavy-chaos/shared`
Shared package exporting TypeScript types (`GameState`, `Player`, `Session`, `PubSubMessage`, etc.) and standalone reusable Svelte 5 components used by both `extension` and `web`.
